AmneziaWG на MikroTik

Открытый клиент Amnezia VPN (AmneziaWG 1.x и 2.0) для роутеров MikroTik: контейнер RouterOS 7 с веб-интерфейсом. Вся домашняя сеть, отдельные устройства или только нужные сайты идут через замаскированный WireGuard-туннель, и ставить VPN на каждое устройство не нужно.

GitHub Скачать Инструкция по настройке

Возможности

  • Подключение по ключу vpn:// из приложения Amnezia, по файлу .conf или по SSH к своему серверу Amnezia (контейнер сам создаст клиента).
  • Режимы: вся сеть, выбранные устройства или выбранные сайты (домены, IP, подсети). Kill switch и DNS через туннель.
  • Исключения по странам: например, российские подсети идут напрямую, мимо VPN.
  • Несколько серверов, переключение в один клик, автоматический переход на резервный сервер за ~15 секунд.
  • Правила RouterOS (routing rules, mangle, address lists) прописываются из веб-интерфейса через REST API.
  • Образ около 10 МБ, около 8 МБ RAM. Архитектуры arm64, arm/v7, amd64 (CHR).

Как поставить

  1. Возьмите образ: роутер скачает его сам из ghcr.io/namikko-chad/amneziawg-mikrotik или Docker Hub namikko/amneziawg-mikrotik, либо загрузите .tar со страницы Releases.
  2. Включите пакет container, создайте сеть контейнера и запустите его по инструкции.
  3. Откройте http://172.18.0.2/, вставьте ключ vpn:// и нажмите Apply.

Частые вопросы

Может ли MikroTik подключиться к серверу Amnezia VPN?

Сам по себе нет: встроенный клиент WireGuard в RouterOS не понимает мусорные пакеты и изменённые заголовки AmneziaWG. Этот проект запускает полный клиент AmneziaWG в контейнере RouterOS 7, а роутер направляет в него трафик обычными правилами маршрутизации.

Какие роутеры подходят?

Любые с RouterOS 7 и пакетом container: arm64 (hAP ax², hAP ax³, RB5009, CCR2004, Chateau ax), arm/v7 (hAP ac², hAP ac³, RB4011, cAP ac) и x86/CHR. Роутеры на mipsbe/mmips (hAP lite, hEX) контейнеры не запускают.

Чем это отличается от awg-proxy?

Прокси-проекты оставляют туннель во встроенном WireGuard RouterOS и переписывают пакеты по пути к серверу. Здесь в контейнере работает полный клиент amneziawg-go, поэтому поддерживаются все параметры AmneziaWG, включая AWG 2.0 (S3, S4, I1–I5), плюс веб-интерфейс, резервный сервер и маршрутизация по устройствам, сайтам и странам.

Можно пустить через VPN только некоторые сайты?

Да. В режиме Selected sites через туннель идут только указанные домены и подсети, а исключения по странам (например, ru) пускают подсети выбранных стран напрямую.

AmneziaWG for MikroTik (English)

amneziawg-mikrotik is an open-source (MIT) AmneziaWG client for MikroTik RouterOS 7, packaged as a container with a web UI. RouterOS's built-in WireGuard client cannot connect to an Amnezia VPN server; this project runs the full amneziawg-go client in a container and routes your whole LAN, selected devices or selected sites through it.

  • Set up with a vpn:// key from the Amnezia app, a .conf file, or SSH access to your Amnezia server.
  • Routing rules, kill switch, DNS and country exceptions are applied from the web UI over the RouterOS REST API.
  • Several servers with automatic failover; about 10 MB image, about 8 MB RAM; arm64, arm/v7 and amd64 (CHR).
